# PhishGuard – Browser Extension
![JavaScript](https://img.shields.io/badge/JavaScript-ES6-yellow)
![Security](https://img.shields.io/badge/Cybersecurity-Phishing%20Detection-red)
![Chrome Extension](https://img.shields.io/badge/Chrome-Extension-blue)


PhishGuard is a lightweight browser extension that analyzes URLs in real time to detect potential phishing attempts using heuristic analysis, threat intelligence, and optional AI-based risk scoring.

## Features
- Real-time URL phishing risk analysis
- Heuristic detection (suspicious domains, patterns)
- Risk score display (0–100)
- Clean popup UI
- Designed with security best practices (no API keys exposed)

## Tech Stack
- JavaScript
- HTML / CSS
- Chrome Extension APIs

## Demo
1. Load the extension in Chrome (Developer Mode)
2. Visit any login page
3. Click the PhishGuard icon to see the risk score

## Why This Project Matters
Phishing remains one of the most common attack vectors. This project demonstrates:
- Security mindset
- Client-side threat detection
- Secure extension design
- Practical cybersecurity tooling
